# ホームページから書き込めるようにする（Googleスプレッドシートの設定）

ホームページの「＋ 日記を書く」「＋ 目標を書く」は、Googleスプレッドシートに保存されます。
書く人はログイン不要で、部の合言葉だけ入れます。
最初に **誰か1人が自分のGoogleアカウントで一度だけ** 次の設定をしてください（10分くらい）。

## 1. スプレッドシートを作る

1. [Googleスプレッドシート](https://sheets.google.com) で新しいスプレッドシートを作ります。
2. 名前は「数学科筋トレ部 ホームページ」など分かりやすいものにします。

### 1-2. これまでのデータ（2026-11-03 に実施済み）

もともと GitHub の JSON ファイルにあった日記・目標・部員・予定などは、すべてこのスプレッドシートに移しました。
JSON ファイルは削除済みです（GitHub の履歴には残っています）。

## 2. スクリプトを貼り付ける

1. スプレッドシートのメニューで **拡張機能 → Apps Script** を開きます。
2. 最初からある `コード.gs`（`Code.gs`）の中身を全部消して、このリポジトリの [`apps-script/Code.gs`](../apps-script/Code.gs) の中身を全部貼り付けます。
3. 💾（保存）を押します。

## 3. 合言葉を入れる

合言葉はスクリプトの中には書かず、ここに入れます（GitHubに公開されないようにするため）。

1. Apps Script の左側の ⚙️ **プロジェクトの設定** を開きます。
2. 一番下の **スクリプト プロパティ → スクリプト プロパティを追加** を押します。
3. プロパティに `PASSPHRASE`、値に部の合言葉を入れて保存します。

合言葉を変えたいときは、ここの値を書き換えるだけです（もう一度公開し直す必要はありません）。

## 4. ウェブアプリとして公開する

1. 右上の **デプロイ → 新しいデプロイ** を押します。
2. 種類の ⚙️ から **ウェブアプリ** を選びます。
3. 次のように設定します。
   - 次のユーザーとして実行: **自分**
   - アクセスできるユーザー: **全員**
4. **デプロイ** を押します。初回は「アクセスを承認」が出るので、自分のアカウントを選んで許可します。
   「このアプリは Google で確認されていません」と出たら、「詳細」→「（安全ではないページ）に移動」で進めます。自分で作ったスクリプトなので大丈夫です。
5. 最後に出る **ウェブアプリの URL**（`https://script.google.com/macros/s/.../exec`）をコピーします。

## 5. ホームページにURLを入れる

[`sheet-config.js`](../sheet-config.js) を開き、コピーしたURLを入れてコミットします。

```js
window.SHEET_API_URL = 'https://script.google.com/macros/s/xxxxxxxx/exec';
```

これで「＋ 日記を書く」「＋ 目標を書く」ボタンが出るようになります。
スプレッドシートには、最初に読み込まれたときに「日記」「目標」のシートが自動で作られます。

## 6. 部員・活動内容・予定なども移す（2026-11-03 に実施済み）

部員・種目・今年の目標と実績・予定・毎週の予定・トレーニングは、ホームページの JSON の中身を
合言葉付きでスクリプトに送って取り込みました（スクリプトの `importData`。中身のあるシートは上書きしません）。

## 7. 月のまとめを自動で作る

毎月1日の朝に、先月の「日記の数・活動した日数・いちばん書いた人・自己ベスト・目標の達成数」を
「月のまとめ」シートに書き、ホームページの「目標と実績」タブにも出します。

1. [`apps-script/Code.gs`](../apps-script/Code.gs) の新しい中身を Apps Script に貼り直して 💾 保存します。
2. **デプロイ → デプロイを管理** → ✏️ → バージョンを **新バージョン** にして **デプロイ** を押します（URL は変わりません）。
3. 上の関数の選択欄で **setupMonthlyTrigger** を選んで ▶ **実行** を押します（最初の1回だけ。権限の許可が出たら許可します）。
4. すぐ試したいときは **summarizeThisMonth** を実行すると、今月の途中経過のまとめができます。

同じ月の行はもう一度作ると上書きされます。「ひとこと」はシートで書き換えても大丈夫です（次に同じ月を作り直すまで残ります）。

---

## 使い方

- **日記を書く**: 日付・書いた人・タイトル・本文を入れて保存します。自己ベストを更新したときは「🏆 自己ベストを更新した」を開いて、種目と重さを入れると、記録のメーターとグラフにも出ます。
- **目標を書く**: 月と「部の目標」か部員の名前を選び、目標を1行に1つ書きます。
- **達成にする**: 目標の「進行中」のバッジを押すと「達成 → 未達成 → 進行中」と切り替わります（スプレッドシートから書いた目標だけ）。
- 合言葉は「このブラウザに覚えておく」にチェックすると、次から入れなくて済みます。

## 直したい・消したいとき（過去の分も同じ）

スプレッドシートを開いて、そのまま直してください。保存ボタンはなく、ホームページを開き直すと反映されます。
行を消せばホームページからも消えます。

| シート | 書くこと |
|---|---|
| 日記 | 日付は `2026-11-03` の形。自己ベストの日は「種目」「重さ(kg)」「回数」も書く |
| 目標 | 月は `2026-11` の形。「誰の目標」は `部` か部員の名前。「状態」はプルダウンで選ぶ |
| 基本情報 | 活動紹介の「活動内容」に出る項目（行を足せば項目が増える）と、部の目標メーターの設定。「活動日」は書かなければ「毎週の予定」から自動で作られる |
| 部員 | 部員の紹介の表。**名前を書き換えると、日記・目標の名前も自動で書き換わる**。表記ゆれは「別名」にカンマ区切りで書く（例: `KsK`） |
| 種目 | 記録を付ける種目。「記録のしかた」を「重さと回数・回数・時間(秒)」から選ぶと、日記の入力欄とグラフの単位が変わる。**種目名を書き換えると、日記の記録とメーターの種目も書き換わる** |
| 今年の目標と実績 | 「種類」をプルダウンで「今年の目標」か「実績」にする |
| 予定 | その日だけの予定。同じ日に毎週の予定があっても、こちらが優先される |
| 毎週の予定 | 「曜日」は `水` や `水,金`。開始日・終了日は空でもよい |
| トレーニング | 今日のトレーニングに日替わりで出る。メニューはセルの中で改行（Mac は ⌘+Enter、Windows は Ctrl+Enter）して1行に1つ |

部員以外の人にも直してもらいたいときは、スプレッドシートの「共有」から、その人を「編集者」にしてください。

## スクリプトを更新したとき

`apps-script/Code.gs` を変えたら、Apps Script に貼り直して保存し、
**デプロイ → デプロイを管理 → ✏️（編集）→ バージョン「新バージョン」→ デプロイ** を押します。
こうするとURLは変わりません（「新しいデプロイ」を押すとURLが変わるので注意）。

## 注意

- 合言葉を知っている人なら誰でも書き込めます。広めすぎないようにしてください。
- ホームページのデータはスプレッドシートにしかありません。スプレッドシートやシートの名前、見出しの行は変えないでください（列の並びは入れ替えても大丈夫です）。
- スプレッドシートが読めないとき（Google側の不調など）は、ホームページに「データの読み込みに失敗しました」と出ます。
