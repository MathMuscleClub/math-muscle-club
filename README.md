# 数学科筋トレ部 ホームページ

数学を愛し、筋肉を愛する「数学科筋トレ部」の公式ホームページです。

## 🌐 公開URL
https://mathmuscleclub.github.io/math-muscle-club/

---

## 現在の機能

活動紹介・活動予定・目標と実績・活動日記・LaTeXタイピングを公開しています。
過去問・口頭試問・ログインの画面と通信処理は、公開ページから取り外しています。
過去問のTeX/PDF、一覧JSON、旧機能の独立ファイル、Supabaseの設定・バックエンドは保管用として残しており、現在のページからは読み込みません。この変更ではSupabase側のリソースは操作しません。
LaTeXタイピングの数式表示にはMathJax CDNへの接続が必要です。

## ローカル確認

リポジトリで `python3 -m http.server 8000` を実行し、`http://localhost:8000/` を開きます。
データは `sheet-config.js` のスプレッドシートから読むので、ローカルでも本物のデータが表示されます。

## ✍️ 部員向け：ホームページの更新マニュアル

ホームページのデータ（部員・活動内容・予定・目標・日記・トレーニング・種目）は、
すべて **Googleスプレッドシート「数学科筋トレ部 ホームページ」** に入っています。GitHub を触る必要はありません。

- **日記と目標を書く**: ホームページの「＋ 日記を書く」「＋ 目標を書く」から書けます（部の合言葉だけでOK）。
- **目標を達成にする**: 目標の「進行中」のバッジを押すと切り替わります。
- **直す・消す・ほかのデータを変える**: スプレッドシートを開いて、そのまま書き換えます（過去の分も同じ）。
  ホームページを開き直すと反映されます。
- **一か所直せば他も変わる**: 「部員」シートで名前を、「種目」シートで種目名を書き換えると、
  日記や目標の同じ名前もまとめて書き換わります。活動紹介の「活動日」は「毎週の予定」から自動で作られます。

シートごとの書き方と、最初の設定・スクリプトの更新のしかたは [docs/spreadsheet-setup.md](docs/spreadsheet-setup.md) にあります。
スプレッドシートを直したい人がいれば、スプレッドシートの「共有」からその人を編集者にしてください。
